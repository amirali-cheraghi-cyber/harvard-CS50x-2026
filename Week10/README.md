# Final Project — Personal Portfolio Website

The CS50x Final Project is a personal portfolio website designed to present my technical background, projects, skills, and interests in cybersecurity and software development.

The website was developed as a personal project and is intended to become part of my professional portfolio in the future.

## Project Overview

The portfolio website brings together information about my technical skills, cybersecurity projects, programming experience, and other relevant work in a structured and professional web interface.

The project was developed using:

* HTML5
* CSS3
* JavaScript

## Main Goals

* Create a professional personal portfolio
* Present cybersecurity and programming projects
* Showcase technical skills and areas of interest
* Provide a structured overview of my background
* Build a foundation for future professional and academic opportunities

## Technologies

* HTML5
* CSS3
* JavaScript
