# Homepage

Homepage is a web development project from CS50x Week 8.

The project involved creating a multi-page personal website using HTML and CSS, with navigation between pages and a consistent visual structure.

## Files

* `index.html` — Main homepage and entry point of the website.
* `linux.html` — Page dedicated to Linux.
* `security.html` — Page covering cybersecurity and security-related topics.
* `tools.html` — Page presenting security and technical tools.
* `styles.css` — CSS stylesheet used to define the visual appearance and layout of the website.
* `specification.txt` — Project specification and requirements.

## Topics Covered

* HTML
* CSS
* Multi-page website structure
* Navigation between webpages
* Hyperlinks
* CSS styling
* Page layout
* Semantic HTML
* Website organization
