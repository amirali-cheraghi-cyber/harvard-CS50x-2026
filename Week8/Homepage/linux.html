Linux for Security

What is Linux?

Linux is a free operating system. It is popular in cybersecurity because it is open and secure.

Why Linux?

  • Open source - you can see the code.
  • Secure - has strong permissions.
  • Many security tools work on Linux.

Kali Linux

Kali Linux is a version of Linux made for security testing. It comes with many security tools already installed.

Basic Commands

  • pwd - show current folder
  • ls - list files
  • cd - change folder
  • mkdir - make a new folder
  • cat - show file content
