# Filter (More)

CS50x — Week 4

A C program that applies image filters to BMP images, including grayscale, sepia, reflection, and blur.

## Overview

This project was completed as part of **CS50x — Introduction to Computer Science**.

The program processes bitmap images and applies different image-processing effects to their pixels.

The "More" version extends the original filter problem by implementing additional image filters.

## Concepts

This project applies several C programming concepts:

* Arrays
* Structures
* Pointers
* Memory manipulation
* File I/O
* Nested loops
* Pixel manipulation
* Image processing
* Algorithms

## Implementation

The program reads pixel data from a BMP image and modifies individual pixels according to the selected filter.

The implemented filters include:

* Grayscale
* Sepia
* Reflection
* Blur

Each filter processes the image pixels according to its own algorithm while preserving the BMP image structure.
