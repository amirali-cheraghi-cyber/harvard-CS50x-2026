# Scrabble

CS50x — Week 2

A C program that calculates the score of a word using the point values assigned to each letter in the game of Scrabble.

## Overview

This project was completed as part of **CS50x — Introduction to Computer Science**.

The program accepts two words as input, calculates their Scrabble scores based on the predefined letter values, and determines which player has the higher score.

## Concepts

This project applies several C programming concepts:

* Arrays
* Strings
* Character manipulation
* Functions
* Loops
* Conditional statements
* Input handling
* ASCII character values
* Case conversion

## Implementation

The program processes each character in the input words and assigns the corresponding Scrabble point value.

The scores of all valid letters are accumulated and then compared to determine the winner.
