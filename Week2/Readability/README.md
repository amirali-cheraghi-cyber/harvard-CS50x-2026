# Readability

CS50x — Week 2

A C program that calculates the readability level of a text using the Coleman-Liau index.

## Overview

This project was completed as part of **CS50x — Introduction to Computer Science**.

The program analyzes a text and calculates the number of letters, words, and sentences. It then uses these values to determine the approximate U.S. grade level required to understand the text.

## Concepts

This project applies several C programming concepts:

* Strings
* Character manipulation
* Loops
* Conditional statements
* Functions
* Input handling
* ASCII character classification
* Mathematical calculations
* The Coleman-Liau index

## Implementation

The program processes the input text character by character.

It counts:

* Letters
* Words
* Sentences

These values are then used in the Coleman-Liau formula to calculate the resulting grade level.
