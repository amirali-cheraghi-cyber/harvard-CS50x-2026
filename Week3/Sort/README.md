# Sort

CS50x — Week 3

An analysis of three sorting algorithms and their relative performance.

## Overview

This project was completed as part of **CS50x — Introduction to Computer Science**.

The project focuses on identifying the sorting algorithms used in three provided programs by analyzing their implementation and performance characteristics.

The programs are compared based on their algorithmic behavior and asymptotic complexity.

## Concepts

This project focuses on:

* Sorting algorithms
* Algorithm analysis
* Asymptotic notation
* Big O notation
* Big Omega notation
* Computational complexity
* Performance comparison

## Implementation

The task involves examining the provided sorting implementations and determining which well-known sorting algorithms they correspond to.

The analysis considers how the algorithms behave with different input sizes and how their running times scale as the input grows.
