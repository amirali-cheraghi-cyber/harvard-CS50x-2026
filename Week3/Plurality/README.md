# Plurality

CS50x — Week 3

A C program that conducts a plurality election and determines the candidate with the most votes.

## Overview

This project was completed as part of **CS50x — Introduction to Computer Science**.

The program accepts a list of candidates, collects votes from voters, and determines the winner based on the candidate receiving the highest number of votes.

## Concepts

This project applies several C programming concepts:

* Arrays
* Structures
* Strings
* Functions
* Loops
* Conditional statements
* Input validation
* Searching
* Command-line arguments
* Vote counting

## Implementation

The program stores candidate information and processes each voter's choice.

For every valid vote, the corresponding candidate's vote count is incremented. After all votes have been processed, the program determines the highest vote count and prints all candidates who achieved that number.
