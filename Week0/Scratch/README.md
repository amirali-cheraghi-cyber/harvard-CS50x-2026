# Scratch

Scratch is the introductory programming project from CS50x Week 0.

The project uses **Scratch**, a visual programming environment developed by the MIT Media Lab. Instead of writing traditional source code, programs are created by connecting visual blocks together.

## Project Overview

The goal of this project was to create an interactive program using Scratch while learning fundamental programming concepts such as:

* Functions and events
* Variables
* Conditional statements
* Loops
* User input
* Program flow
* Interactive behavior

The project provided an introduction to computational thinking and programming logic before moving into text-based programming languages such as C.
