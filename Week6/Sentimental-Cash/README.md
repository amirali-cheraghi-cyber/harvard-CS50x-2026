# Sentimental — Cash

CS50x — Week 6

A Python implementation of the CS50 `Cash` problem.

## Overview

This project was completed as part of **CS50x — Introduction to Computer Science**.

The program determines the minimum number of coins needed to make a given amount of change.

This version implements the problem in Python as part of the **Sentimental** track of CS50x.

## Concepts

This project applies several Python programming concepts:

* Variables
* User input
* Floating-point values
* Integer arithmetic
* Loops
* Conditional statements
* Functions
* Input validation
* Greedy algorithms

## Implementation

The program receives the amount of change owed and calculates the minimum number of coins required.

A greedy approach is used by selecting the largest possible coin denomination at each step until the remaining amount reaches zero.
