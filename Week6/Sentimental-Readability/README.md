# Sentimental — Readability

CS50x — Week 6

A Python implementation of the CS50 `Readability` problem.

## Overview

This project was completed as part of **CS50x — Introduction to Computer Science**.

The program analyzes a text and calculates its readability level using the Coleman-Liau index.

This version implements the problem in Python as part of the **Sentimental** track of CS50x.

## Concepts

This project applies several Python programming concepts:

* Variables
* Strings
* User input
* Loops
* Conditional statements
* Functions
* String manipulation
* Character classification
* Mathematical calculations
* The Coleman-Liau index

## Implementation

The program processes the input text and counts the number of letters, words, and sentences.

These values are then used with the Coleman-Liau formula to calculate the approximate U.S. grade level required to understand the text.
