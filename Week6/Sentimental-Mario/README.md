# Sentimental — Mario (Less)

CS50x — Week 6

A Python implementation of the CS50 `Mario (Less)` problem.

## Overview

This project was completed as part of **CS50x — Introduction to Computer Science**.

The program asks the user for the height of a half-pyramid and prints the corresponding structure using hash (`#`) characters.

This version implements the problem in Python as part of the **Sentimental** track of CS50x.

## Concepts

This project applies several Python programming concepts:

* Variables
* User input
* Strings
* Loops
* Nested loops
* Conditional statements
* Functions
* Input validation
* Formatted output

## Implementation

The program prompts the user for a height within the required range.

It then uses loops to generate the pyramid row by row, producing the required number of spaces and hash characters for each row.
