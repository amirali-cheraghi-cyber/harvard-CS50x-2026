# Mario (Less)

CS50x — Week 1

A C program that recreates a half-pyramid of bricks similar to the pyramids from Super Mario.

## Overview

This project was completed as part of **CS50x — Introduction to Computer Science**.

The program asks the user for the height of the pyramid and prints a left-aligned half-pyramid using hash (`#`) characters.

## Concepts

This project applies several fundamental C programming concepts:

* Variables and data types
* User input
* `do-while` loops
* `for` loops
* Conditional statements
* Functions
* Input validation
* Nested loops
* Formatted output

## Implementation

The program first prompts the user for a pyramid height within the required range.

It then uses nested loops to generate the requested number of rows, with each row containing the appropriate number of bricks.
