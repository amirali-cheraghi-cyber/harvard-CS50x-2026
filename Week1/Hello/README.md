# Hello

CS50x — Week 1

A simple C program that asks the user for their name and prints a personalized greeting.

## Overview

This project was completed as part of **CS50x — Introduction to Computer Science**.

The program takes the user's name as input and displays a greeting using formatted output.

## Concepts

This project introduces fundamental C programming concepts:

* Variables and data types
* Strings
* User input
* Functions
* Formatted output
* Basic program structure

## Implementation

The program prompts the user to enter their name and then uses `printf` to display a personalized greeting.
