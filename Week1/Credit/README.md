# Credit

CS50x — Week 1

A C program that determines whether a credit card number is valid and identifies the card's payment network based on its number.

## Overview

This project was completed as part of **CS50x — Introduction to Computer Science**.

The program validates a credit card number using **Luhn's algorithm** and identifies the card type when applicable.

## Concepts

This project applies several fundamental C programming concepts:

* Variables and data types
* Arithmetic operations
* Loops
* Conditional statements
* Integer manipulation
* Modular arithmetic
* Functions
* Input validation
* Luhn's algorithm

## Implementation

The program processes the digits of the credit card number and applies Luhn's checksum algorithm to determine whether the number is valid.

If the number is valid, the program identifies the corresponding card type based on its length and starting digits.
