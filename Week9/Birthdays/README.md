# Birthdays

Birthdays is a web application project from CS50x Week 9.

The project involves building a simple birthday management application using Flask. Users can interact with the application through a web interface, while the backend handles the application logic and data processing.

## Files

* `app.py` — Main Flask application containing the backend logic and routes.
* `templates/index.html` — HTML template used to display the application's web interface.
* `static/styles.css` — CSS stylesheet used to customize the appearance of the application.
