# Songs

CS50x — Week 7

A SQL-based database analysis exercise focused on querying and analyzing information about songs and artists.

## Overview

This project was completed as part of **CS50x — Introduction to Computer Science**.

The exercise consisted of multiple SQL questions based on a relational database containing information about songs and artists.

The questions covered different types of database operations, including:

* Retrieving records from a database
* Sorting query results
* Limiting results
* Filtering records using conditions
* Calculating aggregate values
* Comparing values against averages
* Working with artist and song information
* Pattern matching with text

The original SQL solution files are not included in this repository in order to avoid publishing the complete solutions and compromising the integrity of the coursework.

## Database

The exercise used a relational database containing information about songs and artists.

The primary tables included:

* `songs`
* `artists`

The `songs` table contained fields related to song characteristics such as title, artist, energy, danceability, valence, tempo, and duration.

## Topics Covered

The exercise provided practical experience with:

* SQL queries
* Relational databases
* `SELECT`
* `WHERE`
* `ORDER BY`
* `LIMIT`
* Aggregate functions
* `AVG`
* Text filtering
* Database analysis
