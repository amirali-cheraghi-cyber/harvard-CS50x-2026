# Fiftyville

Fiftyville is a SQL investigation project from CS50x Week 7.

The task involved analyzing a database of records related to a fictional city in order to identify a thief, determine the thief's destination, and identify the accomplice.

## Topics Covered

* SQL queries
* Filtering data with `WHERE`
* Sorting and limiting results
* `JOIN` operations
* Analyzing relational data
* Investigating records across multiple database tables
* Connecting evidence from different sources
* Step-by-step database investigation

## Investigation Result

The investigation identified:

* **Thief:** Bruce
* **Destination:** New York City
* **Accomplice:** Robin
