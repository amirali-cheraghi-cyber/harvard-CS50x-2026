# Movies

CS50x — Week 7

A SQL-based database analysis exercise focused on querying information about movies, people, and their relationships.

## Overview

This project was completed as part of **CS50x — Introduction to Computer Science**.

The exercise consisted of multiple SQL questions using a relational database containing information about movies, actors, directors, and ratings.

The questions required retrieving and analyzing data using SQL queries, including filtering records, sorting results, and working with relationships between database tables.

The original SQL solution files are not included in this repository in order to avoid publishing complete coursework solutions.

## Topics Covered

The exercise provided practical experience with:

* SQL queries
* Relational databases
* Multiple-table relationships
* `SELECT`
* `WHERE`
* `JOIN`
* `ORDER BY`
* `LIMIT`
* Aggregate functions
* Filtering and searching
* Database analysis

## Database

The exercise used a relational database containing information about:

* Movies
* People
* Directors
* Actors
* Movie ratings

The questions required querying information across related tables to obtain the requested results.
